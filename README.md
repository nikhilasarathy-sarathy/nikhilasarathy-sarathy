## 🚀 Currently Building

### 🧠 URIMAI

**AI-Powered Government Scheme Recommendation Platform**

URIMAI is an AI-powered platform designed to analyze user profiles and
recommend relevant government schemes.

### What it does

- 🔍 Analyzes user profiles
- 📑 Recommends relevant documents
- 🤖 Uses **Gemini AI** for information extraction
- ✍️ Automatically fills user profiles
- ⚠️ Detects conflicts between schemes
- 🔮 Predicts future scheme eligibility

> **Focus:** AI • LLMs • Intelligent Recommendation • Document Processing •
> Full-Stack Development
