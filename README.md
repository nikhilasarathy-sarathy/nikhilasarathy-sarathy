## 🧠 Flagship Project — URIMAI

<table>
<tr>
<td width="100%">

**AI-Powered Government Scheme Recommendation Platform**

URIMAI analyzes user profiles end-to-end and intelligently matches people with the government schemes they're actually eligible for — turning a slow, confusing process into a guided, automated one.

| Capability | Description |
|---|---|
| 🔍 Profile Analysis | Reads and understands user profiles automatically |
| 📑 Document Recommendation | Surfaces exactly which documents a user needs |
| 🤖 AI Extraction | Uses **Gemini AI** to extract information from documents |
| ✍️ Auto-Fill | Automatically populates user profiles |
| ⚠️ Conflict Detection | Flags conflicting or overlapping scheme eligibility |
| 🔮 Predictive Eligibility | Forecasts future scheme eligibility as profiles change |

`Generative AI` `Gemini AI` `LLMs` `Recommendation Systems` `Full-Stack`

</td>
</tr>
